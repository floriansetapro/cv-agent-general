Le CV PDF sera ajouté après réception du document final de Florian.

## Mise à jour

Les sources sont conservées dans le projet de travail local. Construire avec `CV_GITHUB_BASE_PATH=/cv-agent-general node scripts/build-github-pages.mjs`, puis publier le contenu de `dist/client` uniquement dans ce dépôt.

GitHub Pages utilise la branche `main`, dossier `/ (root)`.
